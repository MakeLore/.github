# MakeLore – Community Defaults

This repository contains MakeLore's organisation-wide default
GitHub templates and contribution resources.

Our goal is to make collaboration consistent and easier
across all MakeLore game projects.

## Issue Templates

Our standard issue templates include:

- Bug Report – Report errors and unexpected behaviour.
- Feature Development – Propose gameplay features and improvements.
- Technical Task – Document technical work and implementation tasks.

## Pull Request Template

Our Pull Request template helps contributors explain:

- What they changed.
- Which issue their work addresses.
- How they tested their changes.
- Whether the work is ready for review.

## Contribution Guidelines

- Work through GitHub Issues.
- Create a separate branch for your work.
- Submit changes through Pull Requests.
- Do not push directly to main.
- Link relevant issues to Pull Requests.
- Ask for clarification whenever a task is unclear.

## Maintaining This Repository

These files provide default templates for MakeLore repositories.
Repository-specific templates can override these defaults.
